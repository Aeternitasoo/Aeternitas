---
name: financial-analysis
description: "利用已冻结SEC数据核对年度财务变化、计算口径和资本投入风险。"
---

目标：使用既有财务计算结果解释经营变化，保留主体、期间和口径。

输入：已登记数据别名和具体财务问题。使用research.financial_summary，不通过参数指定任意文件或下载新数据。

步骤：
1. 检查公司名称、CIK、研究日期及财务期间。遇到子公司／母公司名称异常，保留宿主审查说明与未知项，不自行认证合并范围。
2. 阅读收入、营业利润、净利润、既有利润率和同比计算。缺失值保持缺失；不将零与缺失混淆，不把不同财年相加为行业总量。
3. 需要资本开支、折旧、租赁或现金流而工具未提供时，按证据ID查找原文；不能把收入表当成完整资本投入分析。
4. 对金额与比率保留单位、期间和原文／程序计算出处；现金资本开支、非现金融资租赁及包含分红的回报分别处理。

输出：符合任务契约的分析、所用证据和数据缺口。新的金融算术应由宿主提供的受控计算工具处理；当前目录没有计算工具时不要编造结果。

异常：来源哈希变化、数据不齐或时间不合格时停止相关结论；不得修改原始文件或已有公式以使结果通过。技能不授予网络、文件写入或数据库权限。
